## 📚 Engineering Labs & Notes

I use small, reproducible projects to study the behavior of AI systems beyond the model itself:

- LLM inference latency and throughput
- Retrieval and ranking quality
- Evaluation design and error analysis
- Agent failure modes and tool-use reliability
- Edge inference and real-time processing
- Deployment and systems trade-offs

The goal is simple:

> **Build it → measure it → understand why it fails → improve it.**
